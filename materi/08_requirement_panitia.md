# Requirement Peserta untuk Panitia

Salin blok di bawah ini ke daftar requirement panitia. Formatnya mengikuti entri lab lain di daftar yang sama.

```
2. Computing Laboratory
Requirement :
Software :
Browser versi terbaru: Google Chrome, Microsoft Edge, Mozilla Firefox, atau Safari
Tidak perlu memasang aplikasi apa pun

System Requirements:
•⁠  ⁠Perangkat: minimal satu laptop per kelompok (kelompok maksimal 5 orang). Peserta yang hanya membawa HP bergabung dengan laptop teman sekelompoknya; alat juga bisa dibuka di HP
•⁠  ⁠OS: bebas (Windows, macOS, Linux, Android, atau iOS), selama browsernya versi terbaru
•⁠  ⁠Tidak ada syarat RAM atau storage khusus

Lain nya:
Tidak perlu akun, tidak perlu Python, dan tidak perlu pengetahuan machine learning sebelumnya

Link instalasi/download :
Tidak ada instalasi. Alat dibuka langsung di browser:
https://prediktor-computinglab.netlify.app/

Keterangan/ketentuan tambahan : Mohon peserta membuka tautan di atas satu kali sebelum sesi dimulai (misalnya malam sebelumnya atau pagi hari), supaya alat tetap bisa dipakai walaupun Wi-Fi kelas tidak stabil. Laptop dalam keadaan terisi daya penuh. Setiap kelompok membawa pulpen dan kertas untuk kegiatan cadangan tanpa perangkat. Alat tidak mengumpulkan data pribadi apa pun.
```
