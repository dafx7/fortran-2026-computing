# Requirement Peserta untuk Panitia

Salin blok di bawah ini ke format panitia. Ganti tautan placeholder dengan URL alat setelah deploy.

```
LIST REQUIREMENT PESERTA
1. Computing Laboratory
Requirement : Minimal satu laptop per kelompok (kelompok maksimal 5 orang) dengan browser versi terbaru: Google Chrome, Microsoft Edge, Mozilla Firefox, atau Safari. Tidak perlu memasang aplikasi apa pun, tidak perlu membuat akun, tidak perlu Python, dan tidak perlu pengetahuan machine learning sebelumnya. Peserta yang hanya membawa HP akan bergabung dengan laptop teman sekelompoknya.
Link instalasi/download : Tidak ada instalasi. Alat dibuka langsung di browser lewat tautan berikut: [KONFIRMASI: URL alat setelah deploy, sementara https://computinglab.tech]. Mohon peserta membuka tautan tersebut satu kali sebelum sesi dimulai (misalnya saat malam sebelumnya atau pagi hari) agar alat tetap bisa dipakai walaupun Wi-Fi kelas tidak stabil.
Keterangan/ketentuan tambahan : Laptop dalam keadaan terisi daya penuh. Setiap kelompok membawa pulpen dan kertas untuk kegiatan cadangan tanpa perangkat. Alat tidak mengumpulkan data pribadi apa pun.
```
